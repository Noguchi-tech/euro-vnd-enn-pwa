# 基本設計: 旅行用 為替換算PWA

## 画面構成

1. 通貨切替
   - `EUR`
   - `VND`
2. レート種別切替
   - `最新レート`
   - `設定レート`
3. レート表示
   - 現在使用中のレート
   - 更新日時または設定日時
4. 換算対象金額表示
   - 電卓で入力・計算された金額
5. 日本円換算結果
   - `約 xxx 円`
6. 計算過程表示
   - 例: `4 + 4 = 8`
7. 電卓ボタン
   - `0`から`9`
   - `00`
   - `.`
   - `+`, `-`, `×`, `÷`
   - `=`
   - `C`
   - `BS`
8. 設定レート入力UI
   - 設定レートモード時のみ表示する
   - EUR/VNDごとに保存する

## 技術構成

- HTML
- CSS
- JavaScript
- localStorage
- Service Worker
- Web App Manifest
- 為替レート取得API

## API方針

為替レート取得には`fxapi.app`の単一ペアAPIを使用する。

- EUR: `https://fxapi.app/api/eur/jpy.json`
- VND: `https://fxapi.app/api/vnd/jpy.json`

レスポンスの`rate`を、1通貨単位あたりのJPYレートとして扱う。

## オフライン方針

- アプリ本体はService Workerでキャッシュし、オフライン起動可能にする。
- 最新レート取得はオンライン必須とする。
- オフライン時は以下の優先順位で換算可能なレートを使う。
  1. 設定レート
  2. 最後に取得済みの最新レート
- 最新レート取得に失敗した場合は、画面上部のステータス領域にエラーを表示する。

## レイアウト方針

- ルート要素は`100dvh`固定で縦スクロールを抑止する。
- 画面上部に切替とレート情報を集約する。
- 中央に日本円換算結果を大きく表示する。
- 下部に電卓グリッドを固定比率で配置する。
- iPhone 16の縦画面幅を基準に、余白と文字サイズを詰めすぎない範囲で調整する。
