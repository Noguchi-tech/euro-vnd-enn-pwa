# 仕様: 旅行用 為替換算PWA

## 通貨切替仕様

- `EUR`ボタンを押すとEUR換算に切り替える。
- `VND`ボタンを押すとVND換算に切り替える。
- 選択中の通貨ボタンは強調表示する。
- 選択通貨は`selectedCurrency`へ保存する。

## レート切替仕様

### 最新レート

- `最新レート`ボタン押下時に`selectedRateMode = latest`を保存する。
- APIから最新レートを取得する。
- 成功したら取得レートで換算する。
- 失敗したら保存済み最新レートを使用する。
- 保存済み最新レートもない場合は、設定レートの入力を促す。

### 設定レート

- `設定レート`ボタン押下時に`selectedRateMode = custom`を保存する。
- 保存済み設定レートを使用する。
- 未設定の場合は、設定レート入力UIで入力を促す。
- 保存ボタン押下時に通貨別の設定レートと設定日時を保存する。

## 起動時仕様

- `selectedCurrency`を読み込み、最後に使っていた通貨を表示する。
- `selectedRateMode`を読み込み、最後に使っていたレートモードを表示する。
- `latest`の場合は、オンラインなら最新レート取得を試みる。
- オフラインまたは取得失敗時は、保存済みレートを使用する。
- `custom`の場合は、保存済み設定レートを使用する。

## 電卓仕様

- `4 + 4 =`を押すと結果は`8`。
- 表示は`4 + 4 = 8`。
- その後`+ 5`を押すと、表示は`8 + 5`。
- `=`を押すと、表示は`8 + 5 = 13`。
- このとき換算対象金額は`13`。
- その後数字を押すと、新しい計算として開始する。
- その後演算子を押すと、`13`から計算を継続する。

## UI仕様

- iPhone 16の画面でスクロールしない。
- CSSは`height: 100dvh; overflow: hidden;`を基本にする。
- 電卓部分はコンパクトなグリッドにする。
- 結果表示を大きくする。
- レートや更新日時は小さめに表示する。
- ボタンは片手で押しやすいサイズにする。

## PWA仕様

- `manifest.webmanifest`を配置する。
- Service Workerでアプリ本体をキャッシュする。
- キャッシュ対象はHTML、CSS、JavaScript、Manifest、アイコンとする。
- 外部APIはService Workerキャッシュ対象外とし、最新レート取得はネットワーク通信に依存する。
